# and a 1,600-word one is dropped. It is a judgement about whether the article
# says anything the library does not already have, and whether it is reporting
# evidence or filling a keyword slot.
#
# The big block below is one decision, not forty-three. In March 2023 the site
# published a cluster of near-identical pages, most of them on a single day,
# built from one template: "Why This Matters / Where This Goes Wrong /
# Constraints / Execution / Programming / Progression / Common Issues / Role in
# a Program / Takeaway", with the exercise name swapped and whole sentences
# repeated verbatim between files. Across all forty-six pages in that cluster
# there is not one citation, not one named study, and exactly one number in the
# body text - "8-12", quoted in order to dismiss it. They are downstream of the
# cited articles, not sources for them. Three of the forty-six are kept because
# they are actually different: the two conceptual pages the rest paraphrase, and
# the one page with real technique content in it.
#
